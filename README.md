## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

The program copies the image the repository holds (`entry.png`, a JPEG, 1024×1024) to the output directory, byte for byte, so both runs write identical bytes. Node 22, standard library only, no network.
